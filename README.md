# Computational-Cognitive-Neuroscience-Notes

Slides, reading lists and code on computational models of decision making and how they connect to brain data.

## Contents

- `slides/`: slides from each session (PDF)
- `Reference/papers.md`: session dates, topics and readings
- `Reference/resource.md`: tutorials, courses, R packages and Stan resources
- `scripts/`: hierarchical Bayesian reinforcement learning models in Stan (reversal learning)

## Topics so far

- Reinforcement learning on a probabilistic learning task
- Balloon Analogue Risk Task (BART)
- Model-based fMRI and hierarchical Bayesian parameter estimation
- Bayesian inference
- Adaptation to fluctuating intentions of others (social decision making)
